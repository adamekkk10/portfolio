FactCheck settings

Your API key is stored only in this browser's local extension storage (chrome.storage.local). It is never sent anywhere except directly to Anthropic's API (api.anthropic.com) when you run a fact-check, and it is never bundled with or hardcoded into this extension. Uninstalling the extension or clearing its storage removes the key permanently.

Need a key? Create one at console.anthropic.com .
